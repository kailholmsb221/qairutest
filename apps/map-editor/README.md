# Векторная карта здания

Интерактивная SVG-карта двух этажей. Источник — чертежи `packages/map-data/plans/floor-{1,2}.svg`
(нарисованы в Illustrator: стены — штрихи, подписи — текст). Штрихи попадают на экран дословно,
помещения между ними вычисляются автоматически и хранятся в топологической JSON-модели
(`points → walls → rooms.boundary (+ holes)`), которую умеет редактировать этот редактор.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc -b && vite build
npm run check:geometry   # проверка packages/map-data/vector/*.json: схема, замкнутость, щели, самопересечения
python tools/svg2plan.py           # чертежи plans/*.svg → tools/traced/floor-{1,2}.json (+ QA-рендер рядом)
npm run gen:floors                 # tools/traced/*.json + идентичность tools/floor1.ts / floor2.ts → packages/map-data/vector/*.json
```

Дальше в корне репозитория: `pnpm map:build` (→ `building-a.json`, `vector-map.json`, `docs/BUILDING.md`).

## Как чертёж становится картой

`tools/svg2plan.py` (numpy, opencv-python, shapely, svgelements, Pillow):

1. Штрихи чертежа (path/polygon/rect/polyline с обводкой) поворачиваются и вписываются в общий
   `viewBox 1600×1000`; их path data сохраняется дословно (`strokes`) — это стены на экране.
2. Штрихи дискретизируются в ломаные, объединяются в планарную сеть (`grid_size 0.05` — концы
   штрихов Illustrator расходятся на сотые доли). Висячие концы достраиваются до соседних стен
   (T-стыки в пределах `snap`, проёмы в пределах `gap`), проёмы между округлыми торцами стен
   ищутся растровым водоразделом, оставшиеся «горлышки» (комната, открытая в коридор или в
   тело двойной стены) — размытием грани диском и самой короткой хордой поперёк прохода.
   Все такие мостики — стены `virtual: true`, на экране они не рисуются.
3. Сеть полигонизируется; каждая грань — помещение, дыры (острова внутри коридора) остаются
   в `holes`. Узкие грани — тела двойных стен — помещениями не становятся.
4. Подпись на чертеже называет грань, в которой стоит (позиция, угол и размер шрифта
   сохраняются). Для чертежа без подписей позиции задаются в конфигурации `FLOORS` (`anchors`);
   там же — `corridor` (какие безымянные грани считать коридором) и `types` (тип безымянной грани).

`tools/tracedPlan.ts` + `tools/floor{1,2}.ts` — идентичность помещений: точка внутри грани →
id, номер, название, тип. Грани без записи получают имя «Коридор»/«Холл»/«Помещение».

Отладка: `python tools/svg2plan.py floor-2 --qa DIR [--crop x0 y0 x1 y1] [--lines] [--debug] [--dump-face X Y]`.

## Структура

- `src/types/plan.ts` — типы модели; `src/schemas/planSchema.ts` — Zod-схема + ссылочная целостность.
- `src/geometry/` — сборка path из boundary (+ дыры), дуги (bulge), валидация, пересечения, привязки.
- `src/store/` — Zustand: состояние карты, редактор, Undo/Redo.
- `src/components/FloorMap/` — SVG-вьюпорт (zoom/pan), слои; `svg/` — фигуры; `panels/` — UI.
  В режиме просмотра стены — штрихи чертежа, в режиме редактирования — топологические стены.
- `tools/renderSnapshot.ts` — статический SVG-снимок этажа для проверки без браузера.

## Управление

- Колесо — zoom к курсору, перетаскивание — pan, `⤢` — вписать, `1:1` — сброс.
- Клик по помещению — карточка; поиск и легенда (клик — фильтр по статусу).
- `E` — режим редактирования: перетаскивание общих точек (сетка / точки / оси, `Alt` — без
  привязки), добавление/удаление/разделение стен, прямая ↔ дуга и bulge, двери (положение,
  ширина, открывание), номер/название помещения, перенос подписи, проверка геометрии,
  `Ctrl+Z` / `Ctrl+Shift+Z`, экспорт и импорт JSON с валидацией. Правка топологии не меняет
  штрихи чертежа — для этого редактируйте SVG и пересобирайте.
