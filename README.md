# Векторная карта здания

Интерактивная SVG-карта двух этажей, восстановленная вручную по фотографиям бумажных
планов. Растровой подложки в готовой карте нет: все помещения, стены, двери, лестницы и
подписи — программно построенные SVG-элементы из топологической JSON-модели
(`points → walls → rooms.boundary`).

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc -b && vite build
npm run check:geometry   # проверка src/data/*.json: схема, замкнутость, щели, самопересечения
npm run gen:floors       # пересобрать JSON из ручной оцифровки tools/floor1.ts / floor2.ts
```

## Структура

- `src/types/plan.ts` — типы модели; `src/schemas/planSchema.ts` — Zod-схема + ссылочная целостность.
- `src/geometry/` — сборка path из boundary, дуги (bulge), валидация, пересечения, привязки.
- `src/store/` — Zustand: состояние карты, редактор, Undo/Redo.
- `src/components/FloorMap/` — SVG-вьюпорт (zoom/pan), слои; `svg/` — фигуры; `panels/` — UI.
- `src/data/floor-1.json`, `floor-2.json` — модель этажей (генерируется `tools/`).
- `tools/` — DSL оцифровки: единый внешний контур (хорда + касательные дуги), общие точки,
  автоматическое разбиение стен в Т-стыках (`finalizePlan.ts`), статический SVG-снимок.

## Управление

- Колесо — zoom к курсору, перетаскивание — pan, `⤢` — вписать, `1:1` — сброс.
- Клик по помещению — карточка; поиск и легенда (клик — фильтр по статусу).
- `E` — режим редактирования: перетаскивание общих точек (сетка / точки / оси, `Alt` — без
  привязки), добавление/удаление/разделение стен, прямая ↔ дуга и bulge, двери (положение,
  ширина, открывание), номер/название помещения, перенос подписи, проверка геометрии,
  `Ctrl+Z` / `Ctrl+Shift+Z`, экспорт и импорт JSON с валидацией.
